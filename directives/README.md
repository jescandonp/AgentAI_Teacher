# Directivas (Capa 1: Qué hacer)

Este directorio contiene los Procedimientos Operativos Estándar (SOPs) en formato Markdown.

## Propósito
- Definir objetivos claros, entradas esperadas, herramientas/scripts a utilizar (`execution/`), salidas y casos extremos.
- Servir como instrucciones en lenguaje natural para la orquestación del agente.
- Son documentos vivos: deben actualizarse conforme se descubran restricciones de APIs, mejores prácticas, casos extremos o tiempos de respuesta.
