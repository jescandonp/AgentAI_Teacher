# Ejecución (Capa 3: Hacer el trabajo)

Este directorio contiene scripts de Python deterministas.

## Propósito
- Contener las herramientas que realizan el trabajo pesado: llamadas a APIs, procesamiento de datos, scraping, operaciones de archivos e interacciones con bases de datos.
- Scripts testeables, rápidos y confiables.
- Toda configuración sensible o tokens de API deben leerse desde el entorno (`.env`).
